**Thema:** Nachhaltiges Bauen

```

- Materialien umweltfreundlich wählen
- Energieeffizienz berücksichtigen
- Lebenszykluskosten beachten
```

### Test 2: Mittlere Stichpunkte (Mittel)

**Thema:** Bauhaus-Bewegung

```
- Bauhaus 1919 in Weimar gegründet
- Walter Gropius Gründer
- Vereinigung Kunst, Handwerk, Technologie
- Form follows function
- Einfluss auf moderne Architektur weltweit
- 1933 von Nazis geschlossen
```

### Test 3: Ausführliche Notizen (Komplex)

**Thema:** Parametrisches Design in der zeitgenössischen Architektur

```
- Parametrisches Design = algorithmische Entwurfsmethode
- Verwendung von CAD-Software (Grasshopper, Rhino)
- Ermöglicht komplexe organische Formen
- Zaha Hadid wichtige Vertreterin
- Beispiele: Heydar Aliyev Center Baku, Galaxy SOHO Beijing
- Vorteile: Optimierung, Variation, Effizienz
- Nachteile: hohe Baukosten, Komplexität in Umsetzung
- Verbindung zu biomimetischen Prinzipien
- Zukunft: KI-Integration, generatives Design
```

### Test 4: Rohtext mit Fragmenten (Realistisch)

**Thema:** Städtebauliche Verdichtung

```
Verdichtung Städte notwendig
Flächenverbrauch reduzieren
Aber: Lebensqualität erhalten!
Grünflächen wichtig

Verkehrsinfrastruktur anpassen
Beispiel Wien - erfolgreiche Nachverdichtung
Auch: mixed-use developments
Erdgeschosszone aktiv nutzen
```

### Test 5: Technisches Thema (Fachspezifisch)

**Thema:** Tragwerksplanung bei Hochhäusern

```
- Vertikale Lastabtragung primär
- Horizontale Stabilisierung durch Aussteifungssysteme
- Kern-Systeme (Aufzugskern als Stabilisierungselement)
- Rahmentragwerke bei niedrigeren Hochhäusern
- Tube-in-Tube-System bei Supertall Buildings
- Windlasten kritisch ab 150m Höhe
- Finite-Elemente-Methode für Berechnung
- Materialwahl: Stahlbeton vs. Stahlkonstruktion
- Schwingungsverhalten berücksichtigen
```

```
12.-16. Jahrhundert
Hauptmerkmale: Spitzbogen, Rippengewölbe, Strebewerk
Lichtführung zentral
```

## ✏️ MODUS: KORREKTURLESEN

### Test 1: Rechtschreibfehler (Einfach)

**Thema:** Bauhaus

```
Das Bauhaus war eine deutsche Kunstschuhle, die von 1919 bis 1933 existierte. Sie wurde von Walter Gropius in Weimar gegründet und hatte großen Einfluß auf die moderne Architektur. Die Bewegung strebte die Verreinigung von Kunst und Handwerk an. Viele bedeutende Architeckten und Designer gingen aus dem Bauhaus hervor.
```

**Fehler:** Kunstschuhle, Einfluß (alte RS), Verreinigung, Architeckten

### Test 2: Grammatikfehler (Mittel)

**Thema:** Nachhaltiges Bauen

```
Nachhaltige Architektur berücksichtigt ökologische Aspekte während der gesamte Lebenszyklus eines Gebäudes. Die Wahl von Baumaterialien sind dabei von entscheidender Bedeutung. Recycelte Materialien trägt zur Reduzierung des CO2-Fußabdrucks bei. Auch die Energieeffizienz spielt eine wichtigen Rolle für die Nachhaltigkeit.
```

**Fehler:** gesamte (Gen. falsch), sind (Sg. nötig), trägt (Pl. nötig), wichtigen (Akk. falsch)

### Test 3: Zeichensetzung (Mittel)

**Thema:** Moderne Architektur

```
Die moderne Architektur die im frühen 20. Jahrhundert entstand zeichnet sich durch klare Linien aus. Le Corbusier einer der wichtigsten Vertreter entwickelte fünf Punkte der Architektur die bis heute einflussreich sind. Dazu gehören die Pilotis die freie Grundrissgestaltung die freie Fassadengestaltung das Langfenster und die Dachterrasse.
```

**Fehler:** Fehlende Kommas bei Relativsätzen, Aufzählungen

### Test 4: Stilistische Schwächen (Komplex)

**Thema:** Stadtplanung

```
Die Stadtplanung ist sehr wichtig für die Entwicklung von Städten. Es gibt viele verschiedene Aspekte, die man beachten muss. Die Verkehrssituation ist ein wichtiger Punkt, den man nicht vergessen darf. Auch Grünflächen sind wichtig. Man sollte darauf achten, dass genug Parks vorhanden sind. Die soziale Infrastruktur spielt ebenfalls eine große Rolle in diesem Zusammenhang.
```

**Fehler:** Umgangssprache ("sehr", "viele", "man"), Redundanzen, Passivkonstruktionen vermeidbar

### Test 5: Fachterminologie falsch (Fachspezifisch)

**Thema:** Tragwerkslehre

```
Bei der Planung von Gebäudetragwerken müssen die Druckkräfte und Zugkräfte berücksichtig werden. Das Fundament überträgt die Kräfte vom Gebäude in den Boden. Stahlträger sind sehr stabil und werden deshalb oft in der Architektur verwendet. Die Statik muss von einem Ingenieur berechnet werden, damit das Gebäude nicht umfällt.
```

**Fehler:** "berücksichtig" (falsche Form), "umfällt" (zu umgangssprachlich für Fachtext), "sehr stabil" (nicht präzise)

### Test 6: Gemischte Fehler (Realistisch)

**Thema:** Architektonische Konzepte

```
Die architektur des 21. Jahrhunderts ist gepregt durch den Einsatz moderner Technologien und nachhaltiger Materialien. Viele Architeckten setzen auf parametrische Entwürfe die komplexe organische Formen ermöglichen. Diese Gebäude zeichnet sich durch eine hohe Energieeffizienz aus und fügen sich harmonisch in ihre Umgebeung ein. Digitale Planungsmethoden wie Building Information Modeling (BIM) werden zunehmend zum Standard in der Branche.
```

**Fehler:**
- architektur (Großschreibung)
- gepregt (geprägt)
- Architeckten (Architekten)
- Komma fehlt nach "Entwürfe"
- zeichnet sich (zeichnen sich - Plural)
- Umgebeung (Umgebung)

### Test 7: Wissenschaftlicher Stil (Akademisch)

**Thema:** Denkmalpflege

```
Die Denkmalpflege beschäftigt sich mit dem Erhalt und der Restauration von historischen Bauwerken. Hierbei muss man zwischen verschiedenen Ansätzen unterscheiden, wie zum Beispiel der konservierenden oder der rekonstruierenden Denkmalpflege. Es ist wichtig, dass man die historische Substanz möglichst bewahrt. Moderne Eingriffe sollten reversibel sein, damit spätere Generationen auch noch was davon haben. Die Charta von Venedig aus dem Jahr 1964 legt die wichtigsten Grundsätze fest.
```

**Fehler:**
- "man" (unpersönlich, besser: "ist zu unterscheiden")
- "wie zum Beispiel" (akademisch besser: "etwa")
- "wichtig, dass" (besser: nominalstil)
- "was" (umgangssprachlich für "etwas")

### Test 8: Lange Sätze & Komplexe Strukturen

**Thema:** Urbanisierung

```
Die zunehmende Urbanisierung, die weltweit zu beobachten ist führt dazu das immer mehr Menschen in Städten leben, was wiederum große Herausvorderungen für die Stadtplanung mit sich bringt, denn die Infrastruktur muss entsprechend ausgebaut werden und gleichzeitig sollte auch auf die Lebensquallität der Bewohner geachtet werden, wobei Grünflächen und öffentliche Räume eine wichtige rolle spielen und nicht vernachläßigt werden dürfen.
```

**Fehler:**
- Komma fehlt nach "ist"
- "das" → "dass"
- "Herausvorderungen" → "Herausforderungen"
- "Lebensquallität" → "Lebensqualität"
- "rolle" → "Rolle"
- "vernachläßigt" → "vernachlässigt" (neue RS)
- Bandwurmsatz, besser aufteilen

## 📋 VERWENDUNGSHINWEISE

### Für Ausformulieren-Tests:
1. Kopieren Sie einen der Stichpunkt-Texte
2. Fügen Sie ihn ins linke Feld ein
3. Wählen Sie "Modus: ausformulieren"
4. Klicken Sie "Ausformulieren"
5. Testen Sie die selective diff feature durch Klicken auf einzelne Änderungen

### Für Korrekturlesen-Tests:
1. Kopieren Sie einen der fehlerhaften Texte
2. Fügen Sie ihn ins linke Feld ein
3. Wählen Sie "Modus: korrekturlesen"
4. Klicken Sie "Korrektur lesen"
5. Überprüfen Sie, ob Fehler korrekt erkannt werden
6. Testen Sie accept/reject für einzelne Korrekturen

### Empfohlene Testreihenfolge:
1. **Test 1 (Ausformulieren)** - Einfacher Einstieg
2. **Test 1 (Korrekturlesen)** - Basis-Korrekturen
3. **Test 3 (Ausformulieren)** - Komplexerer Inhalt
4. **Test 6 (Korrekturlesen)** - Realistische Fehler
5. **Test 10 (Ausformulieren)** - Performance-Test

### Was zu testen ist:
- ✓ Klicken auf einzelne Änderungen
- ✓ State-Cycling: PENDING → ACCEPTED → REJECTED
- ✓ "Alle akzeptieren" / "Alle ablehnen" Buttons
- ✓ Statistik-Anzeige aktualisiert sich
- ✓ "Text anzeigen" zeigt finalen Text
- ✓ "← Übernehmen" respektiert Auswahl
- ✓ "Kopieren" kopiert finalen Text
- ✓ "Speichern" speichert finalen Text

## 🐛 BEKANNTE EDGE CASES

### Edge Case 1: Keine Änderungen
Wenn der Text bereits perfekt ist, sollten keine klickbaren Änderungen erscheinen.

### Edge Case 2: Nur Löschungen
Text wird kürzer - testen Sie das Ablehnen von Löschungen.

### Edge Case 3: Nur Einfügungen
Text wird länger - testen Sie das Ablehnen von Einfügungen.

### Edge Case 4: Deutsche Sonderzeichen
